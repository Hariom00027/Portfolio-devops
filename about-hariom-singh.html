Who is Hariom Singh?

I'm Hariom Singh, a DevOps engineer. I started as a product engineer at Saarthix, writing Spring Boot services and React screens and leading the engineering team. When it was time to go to production there was no infrastructure team, so I took over everything the product runs on. Today I lead project engineering at Saarthix and run its whole production platform myself: Cloudflare at the edge, load balancing, an API gateway, containerised services, CI/CD and monitoring.

That path from shipping features to running the platform is why I care about both sides of DevOps. I know what developers need from a pipeline, and I know what production needs from the code. I'm now looking for DevOps, Cloud, SRE and Platform Engineering roles where reliability, security and automation matter.

What I work on

  • Hosting and edge: Cloudflare DNS, CDN, TLS and WAF in front of a load-balanced origin, with an API gateway as the single front door.
  • Delivery: CI/CD pipelines that lint, test, scan, build and deploy on every push, and infrastructure kept as code.
  • Containers: Dockerised Spring Boot and React services and Docker Compose stacks with health-checked start-up.
  • Reliability and cost: monitoring and alerting that let one person run production, and an architecture designed to keep the bill small.
